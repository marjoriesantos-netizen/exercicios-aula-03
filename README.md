# Exercícios Aula 03

Projeto web desenvolvido anteriormente na disciplina, utilizando Node.js.

## Descrição

Este projeto contém os exercícios desenvolvidos durante a Aula 03, utilizando recursos do Node.js para criação e execução de um servidor web.

## Tecnologias utilizadas

* Node.js
* JavaScript
* HTTP
* Git e GitHub

## Como executar

1. Instale o Node.js.
2. Clone o repositório.
3. Abra a pasta do projeto no terminal.
4. Execute:

```bash
npm install
```

5. Inicie o servidor:

```bash
node server.js
```

6. Acesse o endereço indicado pelo servidor no navegador.

## Estrutura do projeto

* `server.js` — arquivo principal do servidor.
* `package.json` — configurações e dependências do projeto.
* `package-lock.json` — registro das versões das dependências.
* `data` — arquivos utilizados pelo projeto.
* `.gitignore` — arquivos e pastas que não devem ser enviados ao GitHub.
